# Бизнес анализатор

React приложение за визуален анализ на дневните продажби на персонализирани
бутилки. Данните се зареждат директно от Google Sheets; мартенският план е
хипотетичен сценарий, изчислен спрямо средния темп извън 12–16 февруари.

## Стартиране

```sh
npm install
npm run dev
```

За production build:

```sh
npm run build
npm run preview
```

Източникът на данни е публичната таблица, посочена в приложението. За успешно
зареждане е необходима интернет връзка и достъп до Google Sheets.
